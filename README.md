# 🧮 Simple Calculator (Python)

A beginner-friendly command-line calculator built using Python. This application performs basic arithmetic operations based on the user's choice.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ⚠️ Handles division by zero
* 🖥️ Simple menu-driven interface

## 🛠️ Technologies Used

* Python 3

## 📁 Project Structure

```text
simple-calculator/
│── calculator.py
│── README.md

```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/simple-calculator.git
```

2. Navigate to the project folder:

```bash
cd simple-calculator
```

3. Run the program:

```bash
python calculator.py
```
